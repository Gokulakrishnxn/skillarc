## Overview

Hermes Tweet adds native Xquik tools to Hermes Agent. Use it for social
listening, account research, trend analysis, or reviewed account actions.

The plugin separates catalog discovery, reads, and actions:

- `tweet_explore` searches the bundled endpoint catalog. It makes no API call
  and works without an API key.
- `tweet_read` calls catalog-listed read endpoints after `XQUIK_API_KEY` is
  configured.
- `tweet_action` handles private reads and mutations. It stays disabled unless
  `HERMES_TWEET_ENABLE_ACTIONS=true`.

## Install

```bash:install.sh
hermes plugins install Xquik-dev/hermes-tweet --enable
hermes plugins list
```

Create an API key in Xquik. Add it to the Hermes runtime environment:

```bash:configure.sh
export XQUIK_API_KEY="xq_YOUR_KEY"
export HERMES_TWEET_ENABLE_ACTIONS="false"
```

Restart Hermes after changing environment variables.

## Read-Only Workflow

Start with catalog discovery. Invoke only a path returned by the catalog:

```text:prompt.txt
Use tweet_explore to find read-only trend and account endpoints. Call
tweet_read only for the selected catalog paths. Do not call tweet_action.
```

Without an API key, Hermes should expose only `tweet_explore`.

## Approval-Gated Actions

Keep actions disabled for research. Enable them only after the user approves
private reads or account-changing operations:

```bash:actions.sh
export HERMES_TWEET_ENABLE_ACTIONS="true"
```

Never place secrets in prompts or tool arguments. Secrets include API keys,
cookies, account credentials, and private tokens.
